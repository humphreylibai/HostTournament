# Host Tournament

A Mount & Blade II: Bannerlord (v1.5.5) mod that lets the player host a tournament in any town that isn't currently hosting one, by paying a gold prize fee.

## Features

- **Host tournaments on demand**: Add a "Host Tournament" option to the town menu. Pay 5000 denars to start a tournament in the current town.
- **No cooldown**: Host as often as you like — the only restriction is that the town must not already be hosting a tournament.
- **Arena menu enhancement**: When you visit the arena, the menu now lists all towns currently hosting tournaments across the map.
- **Tournament icon**: The menu option shows the practice-fight icon.
- **No Harmony dependency**: Pure `CampaignBehavior` + game menus.

## Install

1. Copy the `HostTournament` folder into `Mount & Blade II Bannerlord/Modules/`.
2. Launch the game, enable the module in the launcher.

## Usage

1. Enter a town that is not currently hosting a tournament.
2. Select "举办竞技大赛（缴纳奖金）" from the town menu.
3. Pay 5000 denars — the tournament is created (prize generated by the game).
4. Choose to join immediately or later.

## Configuration

Edit `src/HostTournament/HostTournamentConfig.cs`:

| Setting | Default | Description |
|---------|---------|-------------|
| `HostGoldCost` | 5000 | Gold required to host a tournament |
| `AskToJoinAfterHost` | true | Ask whether to join immediately after hosting |
| `VerboseLog` | false | Verbose file logging |

Rebuild after changing: `dotnet build -c Release` in `src/HostTournament/`.

## Build

```
cd src/HostTournament
"C:\Program Files\dotnet\dotnet.exe" build -c Release
```

The DLL is auto-copied to `bin/Win64_Shipping_Client/`.
